Before launching several agents at once, re-read the user's latest word on limits and pick each agent's tier by it;
a running agent is not stopped just to change its tier when the context it already built would be thrown away.
Default to the simplest subagent that can do the job, the lowest tier that fits. Every agent gets one narrow task
(one root or one mechanism, disjoint files), never a fat brief with several: a long-running agent re-reads its growing
context on every step.
